# TSB Hub v0.8.13-dev

Локальная версия TSB Hub для запуска через `index.html`.

## Изменения 0.8.13-dev

- Исправлена мобильная нижняя навигация: панель больше не должна перекрывать кнопки и нижний контент.
- Нижняя панель на телефоне стала компактнее: 7 вкладок раскладываются в 2 ряда вместо высокого блока.
- Добавлена увеличенная безопасная зона снизу для всех вкладок.
- Toast-уведомления подняты выше нижней панели.

## Запуск

Откройте файл `index.html` в браузере.
