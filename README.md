# TSB Hub v0.6.0-dev

Единое приложение TSB/TSBH: задачи, питание, вес, важные даты, выбранная дата, экспорт/импорт JSON.

## Что изменилось в 0.6.0-dev

- Подготовка к запуску через GitHub Pages.
- Добавлена адаптивная раскладка под ПК и Android.
- На ПК сохраняется боковая панель с календарём.
- На телефоне боковая панель скрывается, календарь доступен через верхнюю кнопку даты.
- Нижняя навигация перестраивается в мобильный формат.
- Карточки, формы и вкладки адаптированы под узкий экран.
- Добавлен `.nojekyll` для GitHub Pages.
