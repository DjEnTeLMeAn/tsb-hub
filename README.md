# TSB Hub v0.8.12-dev

Готовая локальная версия сайта. Запуск: открыть `index.html` в браузере.

## Изменения 0.8.12-dev

- Выровнены заголовки, кнопки и сворачиваемые блоки в парных карточках.
- Во вкладке «Сегодня» выровнены блоки задач, питания, финансов, ближайших дат и незавершённых задач.
- Во вкладке «Питание» выровнены карточки «Вес недели» и «Заметка дня».
- Во вкладке «Финансы» плановые поступления и обязательные расходы теперь сворачиваются и разворачиваются.
- В настройках скрыты блоки «Внешний вид», «Диагностика версии» и «PWA-диагностика».
- Версия обновлена до 0.8.12-dev.

## Проверка

- Основной файл запуска: `index.html`.
- Проверка JS: `node --check js/app.js`.
- Архив содержит полную структуру сайта.
