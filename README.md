# TSB Hub v0.7.1-dev

Этап 0.7: первая полноценная PWA-обвязка для GitHub Pages.

## Что есть

- рабочее ядро 0.6.0 сохранено;
- `manifest.json` подключён;
- `service-worker.js` включён;
- приложение можно открыть через GitHub Pages и установить на Android через Chrome;
- оболочка приложения кэшируется для офлайн-запуска;
- личные данные по-прежнему хранятся только локально в браузере пользователя.

## Проверка

1. Загрузить содержимое этой папки в корень репозитория `tsb-hub`.
2. Открыть `https://DjEnTeLMeAn.github.io/tsb-hub/index.html`.
3. Обновить страницу один раз после первого открытия.
4. Открыть настройки и проверить PWA-диагностику.
5. На Android открыть эту же ссылку в Chrome и выбрать «Установить приложение» / «Добавить на главный экран».

## Важно

Не загружать в репозиторий личные экспортированные данные (`tsb_data.json`, архивы, backup-файлы).
