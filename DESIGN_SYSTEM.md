# TSB Hub — дизайн-система

Цель: менять внешний вид без поломки логики вкладок.

## Правило
Логику приложения не трогаем при смене дизайна. Меняем только:

- CSS-переменные в `:root`;
- классы карточек, кнопок, бейджей и форм;
- SVG/иконки;
- размеры отступов через `--space-*`.

## Основные токены

- `--bg` — фон страницы;
- `--card` — фон карточек;
- `--text` — основной текст;
- `--muted` — вторичный текст;
- `--line` — границы;
- `--accent` — основной акцент;
- `--danger` — опасные действия;
- `--radius` — скругления;
- `--tap` — минимальный размер клика.

## Компоненты, которые нельзя переписывать с нуля без причины

- `.tabs` / `.tab-button`;
- `.card`;
- `.task-card`;
- `.meal-card`;
- `.important-card`;
- `.form-grid`;
- `.modal-card`;
- `.badge`;
- `.week-grid` / `.day-column`.

Если нужен новый стиль, сначала меняем токены и CSS этих компонентов, а не HTML/JS-логику.
